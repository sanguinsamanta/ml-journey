#  Diabetes Linear Regression (Scikit-Learn)

A beginner-friendly Machine Learning project that demonstrates how to build a simple **Linear Regression** model using **Scikit-Learn**.

The model predicts diabetes disease progression using a **single feature (BMI)** from the built-in Diabetes dataset.

---

##  Project Overview

This project covers the complete workflow of a basic supervised machine learning model:

* Loading a dataset
* Selecting a feature
* Reshaping data for training
* Splitting data into training and testing sets
* Training a Linear Regression model
* Making predictions
* Visualizing the regression line using Matplotlib

This project was created as part of my Machine Learning learning journey.

---

##  Technologies Used

* Python
* NumPy

##  Dataset

This project uses the **Diabetes Dataset** provided by Scikit-Learn.

Feature used:

* **BMI (Body Mass Index)**

Target:

* Disease progression
